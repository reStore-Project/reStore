# reStore

**A modern revival of the classic Windows Store experience.**

reStore is a community-driven app platform inspired by the Windows Store experience of the Windows 8.1 and Windows 10 era.

Our goal is to bring back the simplicity, design, and software ecosystem of a time when Windows apps were built around a clean, touch-friendly experience.

## Welcome to reStore

Discover applications, explore new software, and find apps made for the classic Windows experience.

> **We launched!**

reStore is currently under development. More applications and features will be added over time.

## Features

* 🖥️ Classic Windows-inspired experience
* 📦 Application discovery and downloads
* ⚙️ Runtime support for applications that require additional components
* 🖼️ Application screenshots and information
* 🔎 Search and browse applications
* 🛠️ Community-driven development

## Platforms

### reStore Web

The web-based version of reStore, designed to provide access to the catalog from modern browsers.

### reStore X

A planned version focused primarily on Windows 10 and its application ecosystem.

## Applications

Applications submitted to reStore should be functional, properly packaged, and provide a useful experience.

We don't want reStore to become a collection of unfinished templates or low-quality applications. Each submission should meet basic quality standards before being included in the catalog.

## Development

reStore is an ongoing community project. Contributions, ideas, application submissions, and improvements are welcome.

More information about contributing will be provided as development progresses.
